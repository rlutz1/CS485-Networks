**NETWORKS: computers talking to computers**

## internet structure

**system perspective**: thinking about hardware/software interations; looking @ how components interact together (and if they interact well)
+ generally all pieces interacting (ie, community & company)

computer becoming an outdated term, hence
+ **end-systems** or **hosts**
+ hosts
  + **client** or **server**

**edge-systems**: things connected to the internet

**packet switches**: abstracting any types of devices that assist in data forward and backing
+ router IS-A packet switch
  
**communication link**: physical medium that packets travel through

**transmission rate**: bandwidth, bits/second

**access point**: -> ethernet cable -> router
+ portal to access the network

**network**: collection of connected devices
  
**access network**: immediate connection enablers
+ connects users to service providers
+ service provider infrastructure connects to the general network

**network core**: interconnected routers, networks of networks

**protocols**: control how to communicate with each other
+ order, format, actions taken...
+ must be agreed upon by both

```
edge system -> device -comm-link-> packet switch -> edge system
```

## why networks of networks?

***SCALEABILITY***

+ case: direct links between every single machine pair
  + O(n^2) links!! BAD!!
+ case: one central connection between all machines
```
comp ---- switch ---- comp
           |
           |
           |
          comp
```
  + n devices, n connections, n ports on the router! hardware restrictions come up fast.
+ **case: interconnection of subnetworks == SCALEABLE!**
