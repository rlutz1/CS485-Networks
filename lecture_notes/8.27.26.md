## network stack 

**5 layer network stack**

top -> bottom
`application -> transport -> network - link -> physical (won't talk about here)`

+ basic separation of concerns
+ each loyer implements a protocol
+ each layer uses services of layer BELOW it
  + send info via **encapsulation**

### sending a postal message

steps - sending

`write (message) -> envelope (address) -> package (pack) -> package routing`

steps - receiving 

`package routing -> package (unload) -> envelope (deposit in box) -> message (read)`

### high level encapsulation

encapsulation overview of sending a message from src -> destination

`[source sends message from app -> physical layer] -> [physical -> (link -> physical);switch] -> [physical -> (network -> link -> physical);router] -> [physical -> (dest phys -> app)]`

app layer -> physical: 

`message -> segment -> datagram -> frame`

### layering data

M -> app layer, message

H, M -> transport layer, append transport layer header bits (now a **segment** (tcp term) or **datagram** (udp term))

N, H, M -> network layer, append network layer header bits for the switch/router (**packet** -- sometimes also called datagram)

L, N, H, M -> link layer, append link layer header bits for router(now a **frame**)

EX: 
```
802.11 -> 802.11 -> IPv4 -> TCP -> HTTPS
(phys -> link -> network -> transport -> application)
```
